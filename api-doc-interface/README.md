# API Documentation Interface

This is an interactive HTML-based interface for exploring the Car Rental Website API documentation. It provides a user-friendly way to browse API endpoints with visual styling and collapsible sections for request/response details.

## How to Use

Simply open the `index.html` file in a web browser to view the documentation. Navigate through the sections using the sidebar menu on the left. Click on 'Show Request' or 'Show Responses' buttons to expand detailed information about each endpoint.

## Features

- Organized navigation menu for different API categories
- Color-coded HTTP methods for easy identification
- Collapsible sections for request parameters and response details
- Responsive design that works on both desktop and mobile devices
