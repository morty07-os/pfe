Overview

Interactive documentation for the Car Rental Website API, built with Node.js and Express, using MongoDB. Supports user authentication, car listings, bookings, and more.

Base URL

https://pfe-uhbw.onrender.com/api

Local: http://localhost:5001/api

Authentication

Most endpoints require JWT authentication. Include token in header:

Authorization: Bearer <token>

Rate Limits

API is rate limited to 100 requests per minute per IP address.

Content Types

Supports application/json for most endpoints and multipart/form-data for file uploads.

Authentication

Manage user registration, login, and profile access with these endpoints.

POST /auth/register

Register a new user and get a JWT token.

Authentication: Not required
{
  "firstName": "string (2-50 chars)",
  "lastName": "string (2-50 chars)",
  "email": "string (valid email format)",
  "password": "string (min 6 chars)",
  "phone": "string (valid phone number)"
}

Note: Email must be unique, password min. 6 chars.

201 Created: User created, returns user data and token.

{
  "token": "string (JWT)",
  "user": {
    "id": "string",
    "firstName": "string",
    "lastName": "string",
    "email": "string",
    "phone": "string",
    "role": "user"
  }
}

400 Bad Request: Email exists or invalid data.

{
  "error": "string (error message)",
  "details": {
    "field": "string (name of invalid field)",
    "message": "string (validation error)"
  }
}

POST /auth/login

Login user and obtain JWT token for protected endpoints.

Authentication: Not required
{
  "email": "string",
  "password": "string"
}

200 OK: Login successful, returns user data and token.

401 Unauthorized: Invalid credentials.

Cars

Manage car listings, search, and details with these endpoints.

GET /cars

Retrieve car listings with optional filters for search.

Authentication: Not required

Pagination: Supports page and limit query parameters (default: page=1, limit=10)

ParameterTypeRequiredDescription
brandstringNoFilter by car brand (case insensitive)
energystringNoFilter by energy type (Essence, Diesel, Electric, Hybrid)
minPricenumberNoMinimum price per day (in local currency)
maxPricenumberNoMaximum price per day (in local currency)
startDatedateNoAvailability start (YYYY-MM-DD format)
endDatedateNoAvailability end (YYYY-MM-DD format)
pagenumberNoPage number for pagination (default: 1)
limitnumberNoItems per page (default: 10, max: 50)

200 OK: Array of car objects with pagination metadata.

{
  "cars": [
    {
      "_id": "string",
      "carName": "string",
      "brand": "string",
      "price": number,
      "energy": "string",
      "available": boolean,
      "images": ["string (URL)"]
    }
  ],
  "total": number,
  "page": number,
  "pages": number,
  "limit": number
}

POST /cars

Create a new car listing with images.

Authentication: Required

Content-Type: multipart/form-data

FieldTypeDescription
carNameStringRequired. Car name
brandStringRequired. Brand name
priceNumberRequired. Price per day
fileFileRequired. Car images

Admin

Administrative endpoints for managing platform content.

GET /admin/cars/pending

Get list of cars pending approval.

Authentication: Required (admin)

Errors

All error responses follow this format:

{
  "message": "Error description"
}

Common error codes:

  • 400 Bad Request: Invalid input data.
  • 401 Unauthorized: Authentication failed.
  • 403 Forbidden: No permission.
  • 404 Not Found: Resource not found.
  • 500 Server Error: Internal server issue.
